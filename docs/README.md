# Moltbot MCP Documentation

- **Integration**: [mcp-central-docs Moltbot series](https://github.com/sandraschi/mcp-central-docs/tree/main/docs/integrations#moltbot-clawdbot)
- **Moltbot upstream**: [docs.molt.bot](https://docs.molt.bot)

## Tools

- `moltbot_ops`: status, health, send, agent, channels.
- `help`: Multilevel help.

## Config

Env prefix `MOLTBOT_MCP_`:

- `GATEWAY_HOST` (default `127.0.0.1`)
- `GATEWAY_PORT` (default `18789`)
- `GATEWAY_TOKEN` (optional)
- `USE_WS` (default `true`)
