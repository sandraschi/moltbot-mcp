# Moltbot MCP Quick Start

1. Configure `MOLTBOT_MCP_GATEWAY_HOST`, `MOLTBOT_MCP_GATEWAY_PORT` (default `127.0.0.1:18789`).
2. Run Moltbot Gateway: `moltbot gateway --port 18789`.
3. Add `moltbot-mcp` to your MCP client (Cursor, Claude Desktop).
4. Use `moltbot_ops` with operation `status` or `health` to verify. Use `help` for docs.
